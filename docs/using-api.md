# Using the API

[Documentation](../README.md)

Use the SPACE HTTP API to create a sandbox, run commands, read their output, and manage the sandbox's lifecycle.

- Follow [Your first sandbox](first-sandbox.md) for a complete Python example, from creation through cleanup.
- Declare applications that start at boot with [Native template startup](native-template-runtime.md).
- Point an existing E2B client at SPACE with the [E2B Compatibility Wrapper](ecw.md), including [full network policies](ecw-network-policy.md).
- Consult the [API Reference](api/index.md) for supported endpoints, request fields, responses, and examples.

If you do not have a local deployment yet, start with [Install and configure locally](installation.md).
