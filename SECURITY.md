# Security

This policy describes how to report security vulnerabilities in SPACE and
which versions receive security fixes. Please use the private reporting
channel below for security-sensitive findings.

**Do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

## Reporting a Potential Security Vulnerability in SPACE

Please report security issues privately using either of the following
channels:

- Web: [Report a vulnerability](https://github.com/perplexityai/SPACE/security/advisories/new)
- Email: [space-team@perplexity.ai](mailto:space-team@perplexity.ai)
- Please include the following information:
  - Affected SPACE version, branch, or commit
  - Type of vulnerability and affected component
  - Instructions to reproduce the vulnerability
  - Proof-of-concept or exploit code, if available
  - Potential impact, including how an attacker could exploit the vulnerability

Use synthetic data where possible and remove credentials, customer data,
and other sensitive information from reproductions and logs.

## Supported Versions

Only the most recent minor release receives security fixes.
